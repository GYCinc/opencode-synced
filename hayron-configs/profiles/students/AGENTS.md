# Student Teaching Profile — AiRon Agents

This profile contains the AiRon ESL teaching agent suite for student session management.

## Agents

- **airon-et** — Primary teaching orchestrator (DeepSeek V4 Pro)
- **airon-context-management** — Student context / TOML management
- **airon-task-design** — Task and activity design
- **airon-report-generation** — Student-facing report generation
- **airon-sanitization** — Data sanitization and cleanup
- **airon-feedback-loop** — Student feedback and RULES.md updates

## Usage

Launch with: `ocx opencode -p students`

Student data lives in `~/By Student/`. This profile isolates teaching workflows from development work.
